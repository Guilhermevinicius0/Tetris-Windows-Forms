# Tetris Windows Forms

[En]
A small Tetris game made in C# with Windows Forms. I built it in my spare time to practice programming and have something fun to play.

## Features

- Move and rotate pieces
- Clear completed rows and earn points
- Track your score and high score during the game
- Play with the seven standard Tetris piece shapes

## How to run

1. Download or clone this repository.
2. Open `WinFormsTetris.sln` in Visual Studio.
3. Build and run the project.

The project targets **.NET Framework 4.7.2** and is intended for Windows.

## Controls

| Key | Action |
|---|---|
| ← / → | Move the piece left or right |
| ↓ | Move the piece down |
| ↑ | Rotate the piece |
| R | Restart the game |

## About

This is a personal learning project. Suggestions and feedback are welcome!

Um pequeno jogo de Tetris feito em C# com Windows Forms. Eu fiz no meu tempo livre para praticar programação e me divertir jogando.

## Features

- Mover e rotacionar peças
- Limpar linhas completas e ganhar pontos
- Acompanhar sua pontuação e recorde durante o jogo
- Jogar com as sete peças padrões do Tetris

## Como rodar o projeto

1. Faça o download ou clone esse repositorio.
2. Abra `WinFormsTetris.sln` no Visual Studio.
3. Faça a build da solução e execute o projeto.

O projeto foi feito para o **.NET Framework 4.7.2** e é planejado para Windows.
